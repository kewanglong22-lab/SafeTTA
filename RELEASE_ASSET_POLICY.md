# Release asset policy

The validated Level-A public paper-statistic replay requires the GitHub repository plus `SafeTTA_replay_assets_v1.zip`.

The frozen colonoscopy SafeTTA PCA64, logistic safety head, and operating threshold are included directly in `artifacts/colonoscopy_safety_estimator/` with exact SHA256 values.

DINOv2-base is a third-party upstream model and is not redistributed here. Historical segmentation checkpoints are optional inference assets and are not required for reproducing the 44 paper-level numerical anchors.
